# HuffmanCompress

## Descrição
Este projeto é um compressor de arquivos .txt, focado em diminuir consideravelmente o tamanho de tais arquivos com a utilização do método de Huffman.
- Projeto em Desenvolvimento

## Funcionalidades
- Compressão e Descompressão de arquivos .txt
- Contrução de árvores binárias
- Geração de Dicionário
- Serialização e Leitura de árvores binárias

## Tecnologias e Ferramentas
- Linguagem: C (Padrão C11).
- Ambiente de Desenvolvimento: Linux Mint e Pop!OS.
- Compilador: GCC.
- IDE: Visual Studio Code e CLion
- Versionamento: Git & GitHub.

## Execução
### Execultando pelo terminal
- Clonar o repositório e acessar a pasta:
```bash
git clone [https://github.com/maxwilliamfs/HuffmanCompress.git](https://github.com/maxwilliamfs/HuffmanCompress.git)  
cd HuffmanCompress
```
- Gerar arquivos de compilação:
```bash
cmake -B build
```
- Compilar o projeto:  
```bash
cmake --build build
```
- Executar o projeto:  
```bash
./build/Huff.exe
```
